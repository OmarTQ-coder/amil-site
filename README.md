# amil.sa

The public website of عامل (Aamel): home, privacy policy, terms and support, in Arabic (/) and English (/en/).

- Edit the text in `src/content/` (the Arabic terms come from `docs/terms-ar.md` in the main project).
- Build: `node src/build.mjs` (writes `docs/`, which GitHub Pages serves).
- Preview: `node src/serve.mjs`, then open http://localhost:8090
